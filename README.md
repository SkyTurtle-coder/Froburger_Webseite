# AV Froburger Website

Statische Website der AV Froburger mit HTML, CSS und JavaScript.

## Projektstruktur

- `index.html` und die weiteren `*.html`-Dateien enthalten die einzelnen Seiten.
- `styles.css` und `script.js` enthalten das gemeinsame Frontend.
- `Bilder/` enthält die publizierten Web-Assets.
- `kalender.ics`, `robots.txt`, `sitemap.xml` und `Zirkel.svg` sind produktive Begleitdateien.

## Lokale Vorschau

Die Website kann direkt ueber `index.html` im Browser geoeffnet oder ueber einen einfachen statischen Server ausgeliefert werden.

## Deployment

Fuer ein Deployment muessen die Dateien im Projektroot sowie der Ordner `Bilder/` veroeffentlicht werden.
